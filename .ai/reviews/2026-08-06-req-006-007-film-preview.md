# Review — REQ-006 / REQ-007 (film EXIF + import preview)

- **Date:** 2026-08-06
- **Status:** specs only (not implemented)
- **Branch:** `feat/dm-analog-ingest`

## Summary

Two planned follow-ons to accepted REQ-005:

1. **REQ-006** — Film ISO + Objektiv EXIF, plus **named gear presets** (camera + ISO + lens saved once under a display name, reselectable on later imports).
2. **REQ-007** — After ZIP extract, job enters `preview`; user rotates frames, then confirms import (then labeling + upload).

## Suggested implementation order

1. REQ-006 job columns + EXIF stamp.
2. REQ-006 presets table + dropdown fill / save / delete.
3. REQ-007 preview pause + gallery + rotate + confirm (uses same job metadata fields).

## Notes

- Lens input: separate numeric fields (mm + aperture) in MVP.
- Preset name example: `Canon AE-1 · Portra 400 · 50mm f/1.8` — unique per user.
- Rotation must rewrite pixels/orientation on disk so PhotoPrism does not depend on browser CSS transforms.
